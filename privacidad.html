Política de privacidad

Última actualización: 13 de octubre de 2026

1. Quién somos

La aplicación "Canal Ave María" es una herramienta privada del propietario del canal de YouTube Ave María TV. Contacto: carlosandresproyectos@gmail.com.

2. Qué datos de Google usa

La aplicación solicita únicamente el permiso de YouTube necesario para subir vídeos al canal de la cuenta que la autoriza. No lee ni guarda comentarios, suscriptores, historial ni datos de los espectadores.

3. Para qué se usan

Exclusivamente para publicar en el canal del propietario los vídeos que él mismo aprueba. No se usan para publicidad, análisis, perfiles ni ningún otro fin.

4. Almacenamiento y seguridad

Las credenciales de acceso se guardan cifradas en un servidor privado del propietario. No se comparten, venden ni transfieren a terceros.

5. Conservación y revocación

Los datos de acceso se conservan mientras el propietario mantenga la autorización. Puede revocarla en cualquier momento en myaccount.google.com/permissions, tras lo cual la aplicación deja de tener acceso.

6. Política de datos de usuario de Google

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google se ajustará a la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

7. Cambios

Esta política puede actualizarse; la fecha de arriba indica la última versión.

English summary: This private application only requests the YouTube permission needed to upload videos to the channel owner's own channel. It does not collect data from viewers or third parties, does not share or sell data, stores credentials encrypted on the owner's private server, and the owner can revoke access at any time at myaccount.google.com/permissions. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: carlosandresproyectos@gmail.com.
